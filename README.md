# FOP — Fichas Ordem Paranormal

Aplicativo web para criar e usar fichas interativas em mesas de Ordem Paranormal RPG.

## Primeira versão

- Criação guiada de agentes.
- Ficha interativa com PV, PE e Sanidade.
- Atributos, dados de combate e áreas de anotações.
- Salvamento automático no navegador, sem cadastro.
- Interface adaptada para computador e celular.

O catálogo completo de origens, trilhas, poderes, rituais e equipamentos será
adicionado gradualmente a partir de materiais de referência, usando cálculos e
resumos próprios em vez de reproduzir os livros.

## Abrir localmente

Sirva esta pasta com qualquer servidor HTTP estático e abra `index.html`.

## Aviso

Projeto de fã não oficial. Ordem Paranormal pertence aos seus respectivos
criadores e detentores de direitos. Nenhum texto integral dos livros é
distribuído neste repositório.
