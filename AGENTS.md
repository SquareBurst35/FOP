# Orientações deste projeto

## Publicação autorizada pelo dono

O usuário pediu em 21/10/2026 que as alterações deste projeto sejam enviadas
diretamente ao GitHub e ao site, sem pedir nova confirmação a cada alteração.

- Depois de concluir uma alteração, execute as validações relevantes, registre
  um commit e faça push para `origin/main`, que publica pelo GitHub Pages.
- Confira se a publicação concluiu e se o site recebeu a versão enviada.
- Se a branch remota avançou, integre as mudanças preservando o trabalho local.
  Não use force push.
- Envie apenas arquivos pertinentes ao projeto. Preserve arquivos locais de
  ferramentas, credenciais, PDFs de referência e extrações fora do commit.
- Se houver um bloqueio real de publicação, explique o motivo ao usuário.
